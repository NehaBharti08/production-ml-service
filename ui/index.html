⚠ NOT A CREDIT DECISIONING SYSTEM. This is an engineering demonstration of ML operations, trained on a public 2007–2015 dataset from a single lender. It has not been validated for lending, has had no fair-lending review, and must never be used to decide anyone's access to credit.

Credit Default Risk

Predicts the probability that a loan charges off. The model is deliberately simple — a calibrated logistic regression — because this project exists to demonstrate operating a model, not building a complex one.
